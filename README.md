# 인사 발령 유인물 (학교별)

학교별 인사 발령 유인물을 원본 엑셀 양식과 같은 모양으로 작성·출력하고, 전체 학교를 엑셀 파일 1개로 내려받는 웹앱입니다.

- 이 저장소에는 **코드(index.html)만** 있습니다. 개인정보는 없습니다.
- 입력 자료는 **사용하는 기기의 브라우저에만** 저장되며, 어떤 서버로도 전송되지 않습니다(보안 정책으로 외부 통신 차단).
- 다른 기기로 옮길 때는 ⚙ 설정 → 저장·불러오기에서 백업 파일(선택 암호화) 또는 엑셀 파일을 사용합니다.

엑셀·CSV·백업(json) 파일은 이 저장소에 올리지 마세요(.gitignore로 막혀 있습니다).
